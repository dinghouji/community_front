## 基于Vue 3的社区物业管理系统实现说明

### 一、前端架构与核心技术

#### 1. Vue 3 Composition API的优势

该项目采用Vue 3的Composition API，具有以下优势：

1. **逻辑组织更清晰**：通过`setup`语法糖，将相关的业务逻辑组织在一起，便于维护。
2. **更好的TypeScript支持**：Composition API提供了更好的类型推断能力。
3. **代码复用性更强**：可以轻松地将业务逻辑封装成自定义Hook，在不同组件间复用。

**示例代码（来自Maintenance.vue）：**
```javascript
<script setup>
import { ref, reactive, onMounted } from 'vue'
import { getMaintenanceRecordPage, saveMaintenanceRecord, updateMaintenanceRecord, deleteMaintenanceRecord } from '@/api/maintenance'
import { getFacilityPage } from '@/api/facility'
import { ElMessage, ElMessageBox } from 'element-plus'

const loading = ref(false)
const tableData = ref([])
const facilityList = ref([])
const dialog = reactive({ visible: false, title: '' })
const form = reactive({ id: null, facilityId: null, description: '', repairerName: '', cost: 0, repairTime: '' })

// 业务逻辑组织在一起
const getList = async () => {
  loading.value = true
  const res = await getMaintenanceRecordPage({ pageNum: 1, pageSize: 20 })
  tableData.value = res.data.records
  loading.value = false
}
</script>
```

- `src/layout`: 定义不同角色的页面布局
- `src/utils`: 存放通用工具函数

### 二、动态路由与权限控制（RBAC实现）

#### 1. 角色权限设计

系统定义了四种用户类型：
- 0: 管理员
- 1: 客服
- 2: 维修人员
- 3: 业主

#### 2. 动态路由挂载逻辑

通过在路由配置中添加`meta.roles`字段，定义每个路由允许访问的角色：

```javascript
// router/index.js
{
  path: '/admin',
  name: 'admin',
  component: () => import('@/layout/AdminLayout.vue'),
  children: [
    { 
      path: 'dashboard', 
      name: 'admin-dashboard', 
      component: () => import('@/views/admin/Dashboard.vue'), 
      meta: { title: '首页', roles: [0, 1, 2] }  // 管理员、客服、维修人员都可访问
    },
    { 
      path: 'user', 
      name: 'admin-user', 
      component: () => import('@/views/admin/User.vue'), 
      meta: { title: '用户管理', roles: [0] }  // 仅管理员可访问
    },
    // ... 其他路由
  ]
}
```

#### 3. 全局路由守卫逻辑

```javascript
// router/index.js
router.beforeEach((to, from, next) => {
  if (to.path === '/login' || to.path === '/register') {
    next()
    return
  }

  const token = localStorage.getItem('token')
  if (!token) {
    next('/login')
    return
  }

  const user = JSON.parse(localStorage.getItem('user') || '{}')
  const userType = user.userType

  if (userType === undefined || userType === null || userType < 0 || userType > 3) {
    localStorage.clear()
    next('/login')
    return
  }

  const roles = to.meta.roles
  if (roles && !roles.includes(userType)) {  // 权限检查
    ElMessage.error('无权访问该页面')
    if (userType <= 2) {
      next('/admin/dashboard')
    } else {
      next('/user/home')
    }
    return
  }

  next()
})
```

### 三、网络请求封装（Axios）

#### 1. 请求拦截器配置

```javascript
// utils/request.js
import axios from 'axios'
import { ElMessage } from 'element-plus'

const service = axios.create({
  baseURL: '/api',  // 统一接口前缀
  timeout: 5000
})

// 请求拦截器 - 自动注入JWT Token
service.interceptors.request.use(
  config => {
    const token = localStorage.getItem('token')
    if (token) {
      config.headers['Authorization'] = token  // 在请求头中添加认证token
    }
    return config
  },
  error => {
    return Promise.reject(error)
  }
)
```

#### 2. 响应拦截器配置

```javascript
// 响应拦截器 - 处理统一结果体
service.interceptors.response.use(
  response => {
    const res = response.data
    if (res.code !== 200) {  // 后端统一返回格式：{ code, message, data }
      ElMessage.error(res.message || 'Error')
      return Promise.reject(new Error(res.message || 'Error'))
    } else {
      return res  // 返回正确的响应数据
    }
  },
  error => {
    ElMessage.error(error.message || 'Request Error')
    return Promise.reject(error)
  }
)
```

### 四、状态管理实现

虽然项目中没有使用Pinia或Vuex进行状态管理，但通过localStorage实现了类似的功能：

```javascript
// 从localStorage获取用户信息
const user = JSON.parse(localStorage.getItem('user') || '{}')
const userType = user.userType

// 在路由守卫中使用
const token = localStorage.getItem('token')
if (!token) {
  next('/login')
  return
}
```

这种方式可以确保页面刷新后用户状态不会丢失，但不如Pinia的持久化插件完善。

### 六、关键技术总结

1. **前端框架**：Vue 3 + Composition API，提供更灵活的逻辑组织方式
2. **UI框架**：Element Plus，提供丰富的组件库和良好的用户体验
3. **状态管理**：通过localStorage实现简单的状态持久化
4. **路由管理**：Vue Router + RBAC权限控制，实现动态路由和菜单
5. **网络请求**：Axios拦截器封装，统一处理请求/响应逻辑
6. **数据可视化**：ECharts图表库，实现数据可视化展示
7. **API设计**：RESTful风格接口，前后端分离架构
